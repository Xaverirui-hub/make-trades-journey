## 1. 会绊到你的三个结构性改动

### ① 导航栏不在 HTML 里了 ⚠️ 最容易踩

33 个页面的 `<nav class="navbar">…</nav>` **全部删掉了**，改成一行
`<script src="assets/nav.js"></script>`。现在页面里搜 `nb-links` 是搜不到的。

要改导航（包括改导航的中文）：

```
改 scripts/extract_nav.mjs  →  跑 node scripts/extract_nav.mjs  →  提交 assets/nav.js
```

**不要**去 33 个 HTML 里找导航，也**不要**手改 `assets/nav.js`（它是产物，
下次重新生成会被覆盖）。

导航文案在 `extract_nav.mjs` 的 `ITEMS` 表里，中英成对：

```js
['courses', 'courses.html', 'Trading Courses', '交易课程'],
```

### ② 字体改自架，不要再引 Google Fonts

`fonts.googleapis.com` 在大陆是被墙的 —— 全站 93 处引用，四套字体
一个都加载不出来，页面一直在用系统后备字体。**从墙外测完全看不出来。**

现在统一走 `<link href="…/assets/fonts/fonts.css">`。

- 新增页面请照抄这一行，**不要**再贴 Google Fonts 的 link
- `assets/fonts/` 与 `assets/vendor/` 都是产物目录，**不要手改**，
  重新生成的指令写在各自的 `README.md` 里
- 这两个目录在 `.gitattributes` 里关掉了行尾转换，别去动

### ③ 21 门课重新编号，八阶段并成六阶段

技术面课程全部归入 Chart Craft，模块号整体重排。

如果你在译文里写过「第 14 课」「Module 08」这类**具体课号**，请重新核对。
